# ANO-002 — Une page sans jeton affiche une trace Streamlit

Cas de test : REC-10  Statut : corrigée  Sévérité : S2  Priorité : P1

Constatée le 17/11/2026 pendant la recette de la version `796ae27`.

## Environnement

Front Streamlit local, page `front/pages/1_Stations.py`, session sans jeton.

## Reproduction

1. Ouvrir la page Stations dans Streamlit sans être connecté.
2. Lire le message et le lien de retour vers la page de connexion.

## Attendu / obtenu

Attendu : `Veuillez vous connecter.` et un lien utilisable vers la connexion, sans trace Python.

Obtenu : `Veuillez vous connecter.`, suivi de `StreamlitPageNotFoundError` et d'une trace sur `st.page_link("front/app.py", ...)`.

## Preuve

Capture fournie pendant REC-10 ; le message d'erreur précise que le chemin doit être relatif au point d'entrée situé dans `front/`.

## Correction

Les trois pages utilisent `app.py` pour le lien de connexion et le retour après déconnexion, chemin relatif au point d'entrée Streamlit. Test de non-régression : rejeu manuel de REC-10 sur les trois pages sans jeton et après déconnexion ; message et lien présents, navigation vers la connexion sans trace. Confirmé le 17/11/2026. Commit : `ad9ec4c`.
