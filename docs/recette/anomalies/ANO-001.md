# ANO-001 — Les doublons exacts ne figurent pas dans le journal d'import

Cas de test : REC-02  Statut : corrigée  Sévérité : S2  Priorité : P1

Constatée le 17/11/2026 pendant la recette de la version `796ae27`.

## Environnement

Base PostgreSQL locale importée, script `scripts/importer.py`, journal `docs/journal-import.csv`.

## Reproduction

1. Exécuter `python scripts/importer.py`.
2. Relever le bilan des trajets et compter les entrées de doublons dans le journal.
3. Comparer au nombre de lignes de `data/trajets.csv`.

## Attendu / obtenu

Attendu : les 12 doublons exacts écartés sont retrouvables dans le journal ; 2002 importés + 16 rejetés + 12 doublons = 2030 lignes.

Obtenu : le bilan compte 12 doublons mais le journal n'en contient aucun ; avec les entrées du journal, 2002 + 16 + 0 = 2018.

## Preuve

`python scripts/importer.py` affiche `Trajets : {'valides': 2002, 'rejets': 16, 'doublons': 12}`. Comptage de `docs/journal-import.csv` : 16 rejets trajet et 0 entrée de doublon.

## Correction

Les boucles de l'importeur journalisent les doublons exacts écartés, avec leur identifiant, colonne, valeur et motif. Test de non-régression : `tests/unit/test_importer.py::test_doublon_exact_journalise_une_fois` (3 variantes réussies).

Rejoué le 17/11/2026 : OK. Le journal régénéré contient 12 doublons exacts de trajets et 16 autres rejets de trajets ; 2002 + 16 + 12 = 2030. Commit : à renseigner après création.
